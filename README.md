# PRM_Infilling_and_scoring
Contains the R codes for infilling missing time series PRM data from the Great Barrier Reef Catchment Loads Monitoring Program using MICE PMM, and the scoring of model outputs. 

The code supports the publication:
_Neelamraju, CA., Mann, RM., Bainbridge, ZT., Orr, D., & Turner, RDR. (2026) From gaps to clarity: Time series imputation for improved assessment of pesticide mixture toxicity and aquatic ecosystem risk. (submitted)_
